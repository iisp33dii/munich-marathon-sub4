# Munich Marathon 2026 // Sub-4 Mission Control 🏃‍♂️⚡

Personalized AI marathon training architecture and biometric intelligence dashboard built for the **Generali München Marathon (October 11, 2026)**.

## 🎯 Target Goal
- **Target Time:** Sub-4:00:00 (Target race pace: **5:34 - 5:38 /km** / Finish ~3:55:00)
- **Schedule:** 3 Running Days + Stacked Strength & Mobility / 4 Complete Rest Days per week.

## 🚀 Live Web App (GitHub Pages)
This repository is configured to run via GitHub Pages.

### How to enable GitHub Pages:
1. Go to your repository on GitHub.
2. Click **Settings** → **Pages**.
3. Under **Branch**, select main (or master) and / (root).
4. Click **Save**.
5. Your dashboard will be live at: https://<YOUR-USERNAME>.github.io/munich-marathon-sub4/

## 📊 Features
- **COROS Biometrics & Readiness Analysis:** Visualizations of 79 running workouts, pace vs heart rate distribution, and volume trends.
- **6-Week Interactive Training Calendar:** Step-by-step workouts with expandable interval breakdowns, stacked strength routines, and local storage checkbox tracker.
- **Specific Gel & Fueling Strategy:** Custom in-race timing for HIGH5 Orange Caffeine & Nrgy Gel 45.
- **Dynamic Pacing & Split Calculator:** Real-time split calculations for 5k, 10k, Half, 30k, 35k, and finish.
- **Munich Marathon Course Strategy:** Tactical kilometer-by-kilometer execution guide.
